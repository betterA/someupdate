真实实现里由本地服务读写这个目录；demo 中数据存在浏览器 localStorage。
opencode run --format json --dir <vault> "<prompt>"
dsh --profile headless "<prompt>"
关掉时每次委派都要在浮层里单独授权。
这个 demo 里什么是真的：笔记编辑 / 搜索 / 新建 / 删除、目录创建 / 重命名 / 删除、笔记移动（拖拽或右键菜单）、任务行委派、状态机、并发队列、流式输出、结论写回（含写前合并不覆盖手写内容）、本地持久化。

目录是单层分组，命名统一为编号前缀 + 全小写：01_todo / 02_sop / 03_skills / 04_project。新建目录会自动转小写、空格转下划线并补下一个编号；「＋ 新建笔记」默认落在 01_todo。每篇笔记只属于一个目录或「未归档」；删除目录不会删笔记。

什么是模拟的：只有 Agent 进程本身。接真 CLI 时替换 AgentAdapter.start() 一处即可，见文件头注释。
